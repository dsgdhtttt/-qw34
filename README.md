# 上门维修项目全套开源系统

源码地址：ym7k.com/20016/


家电、水电、数码、管道等上门维修服务，常常存在派单混乱、师傅调度不合理、报价不透明、工单跟进困难、售后无追溯等问题。这套上门维修全套开源系统，围绕服务类目管理、用户报修下单、智能派单、报价接单、现场施工、结算收款、售后回访、数据统计打造完整业务闭环，支持私有化部署，可二次开发，适合家电维修门店、家政维修公司、物业工程团队、本地综合维修服务商使用，降低自主开发投入，快速搭建线上报修平台。

服务类目与报价管理是系统的基础模块。管理员后台维护维修服务类目，分为家电维修、水电检修、管道疏通、开锁换锁、墙面维修等大类，每个类目下设置细分项目，支持上传服务说明、参考图片。系统可预设标准报价，区分基础服务费、配件费、上门费，还能设置不同区域、不同时段的加价规则。配件库存同步管理，登记配件型号、采购价、售价，库存不足自动提醒补货，维修师傅下单领用配件全程登记，方便成本核算。

用户报修下单与工单提交是面向客户的核心功能。用户通过小程序或者 H5 提交报修订单，填写故障描述、上传故障照片、选择服务类型、填写地址和联系电话，还可以自主预约上门时间。订单提交后生成工单，用户可以随时查看工单状态，包括待派单、师傅接单、上门中、维修中、已完工。个人中心保存历史报修记录、付款凭证，维修完成后可对服务进行评价，为其他客户参考。

智能派单与师傅移动端作业，是提升运营效率的关键。系统支持自动派单和抢单两种模式，可根据距离、师傅擅长工种、当前订单负荷进行智能分配，也支持调度人员手动指派工单。维修师傅在移动端接收工单，查看客户地址、故障信息、预约时间，内置导航直达客户位置。到达现场后，师傅可以在线确认故障，按需修改报价，客户确认后再开始维修。维修完工后上传完工照片，填写故障原因、更换配件，提交完工信息。

收款结算、工单审核与售后回访模块保障交易流程。维修完成后，支持线上支付、线下扫码收款，费用包含上门费、工时费、配件费，明细清晰可查。所有收款记录、配件消耗记录全部留存，支持导出财务对账报表。系统自带售后回访机制，工单完工后自动触发回访提醒，客服联系客户确认维修效果，记录客户反馈，出现复发现象可直接生成二次售后工单。针对投诉工单，管理人员可以全程跟进处理，记录纠纷处理结果。

师傅管理、权限管控与业绩统计模块支撑团队管理。后台统一管理维修师傅账号，标注擅长的维修项目、服务片区，设置师傅提成规则，系统自动根据工单金额核算提成，支持日结、周结、月结。系统划分多级角色权限，平台管理员、调度员、财务、维修师傅权限隔离，师傅只能查看分配给自己的工单，无法查看其他师傅的订单信息。数据看板直观展示每日工单量、完工率、复修率、营收总额、师傅业绩排行，运营人员根据数据调整人员安排、优化定价。

营销工具与扩展能力助力业务拓展。后台可以配置优惠券、新客优惠、套餐活动，吸引客户下单。系统支持消息推送，派单通知、上门提醒、完工通知、回访提醒及时触达师傅和客户。同时预留扩展接口，可对接电子合同、会员储值、物资采购模块，适配会员长期维保服务。整套系统聚焦上门维修全流程，打通客户报修、调度派单、现场施工、结算回访各个环节，解决维修行业派单难、监管难、对账难的痛点，适合本地维修服务商快速搭建专属上门服务平台。
